## Instalação das Dependências

Com o ambiente virtual ativado, execute o seguinte comando na raiz do projeto:

```bash
pip install -r requirements.txt
```

## Como Executar

Com o ambiente virtual ativado, execute os comandos na raiz do projeto.

### 1. Baixar e processar os dados climáticos

```bash
python baixar_clima.py
```

### 2. Explorar os dados e gerar os resultados

```bash
python explorar_clima.py
```

Executar os testes

python -m pytest
